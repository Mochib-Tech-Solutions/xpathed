# Jev evidence planning experiment

Verified 2026-10-01 for [issue #48](https://github.com/Mochib-Tech-Solutions/xpathed/issues/48). This is a development experiment; model availability and prices may change.

## Supported integration

Jev is available through OpenRouter's separate `POST /api/alpha/decisions` endpoint. Request `typesafe/jev-1.13` with the dedicated evaluation key and pin the TypeSafe route; the observed endpoint identifies responses as `typesafe/jev-1.13-20260917`. Ordinary chat-model discovery does not establish availability for this endpoint. The public route snapshot lists $0.042 per million input tokens, free output, a 32,000-token context and no implicit caching. These are informational prices, not application-enforced financial limits. [Model API page](https://openrouter.ai/typesafe/jev-1.13/api), [endpoint metadata](https://openrouter.ai/api/v1/models/typesafe/jev-1.13/endpoints).

The request contains the original instruction as `state` and two named Noul questions: whether target identification needs appearance or spatial evidence. Jev receives no page content and selects neither targets nor the final LLM. Use the existing HTTP client rather than another SDK. The official schemas support provider preferences and token usage; reported dollar cost, provider and generation ID are optional response fields. Missing costs remain unknown in accounting. [Request schema](https://github.com/OpenRouterTeam/typescript-sdk/blob/main/src/models/decisionsrequest.ts), [response schema](https://github.com/OpenRouterTeam/typescript-sdk/blob/main/src/models/decisionsresponse.ts).

Noul is a probability of yes, not an independent confidence score. The initial frozen policy omits an optional evidence group only at probability ≤0.05, includes it at ≥0.95 and retains both groups if either answer is uncertain. These thresholds are experimental, not vendor-guaranteed accuracy. A confident false negative can still remove needed evidence; paired target correctness must detect that loss. [Noul documentation](https://docs.typesafe.ai/primitives/noul).

## Comparison and limits

Both arms use current-view contract 4, one attempt, the same final DeepSeek V4.1 Flash/DeepInfra FP8 route and the same core selection prompt. The assisted arm adds a fixed evidence-availability instruction. It projects optional appearance and geometry from one complete capture while preserving all candidate identities, names, roles, state and frame context. This tests final-model input reduction without claiming cheaper Browser capture. It uses a fresh control; historical Wafer and offline dataset measurements remain separate.

Updated 2026-10-01 after the initial paired run: the classifier retains its 500 ms fallback allowance, while [ADR-0020](../adr/0020-treat-latency-targets-as-evaluation-metrics.md) removes the total two-second response cutoff. The sub-one-second goal and two-second threshold remain evaluation metrics; historical run evidence retains its original timeout policy. Timeout, malformed output, unexpected identity or uncertainty selects full supported evidence. Each arm retains failures and late accounting. Neither cancellation nor a missing cost proves that a request was free. No automatic retry or fallback model is enabled. Provider-configured key limits govern spending under [ADR-0019](../adr/0019-use-provider-key-limits-for-evaluation.md); the shared ledger keeps estimates, actual charges and unknowns distinct.

The initial paired cases have independently reviewed browser labels and known exposure. They test action, scope, plural targets, CSS/layout and readiness; imported dataset labels do not establish those properties. This development pilot can reject an unhelpful technique but cannot qualify a release. Report bytes/tokens, classifier and end-to-end time, full-set correctness, correct results below one second and within two seconds, and both calls' costs. Preserve every original attempt and report successful latency differences only where both arms are correct. A measured benefit would need fresh family-disjoint confirmation before adoption.
