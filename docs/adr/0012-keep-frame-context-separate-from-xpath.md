# Keep frame context separate from document XPath

Issue #4 extends the accepted current-page contract into nested frame documents. Each found target carries its capture-owned frame/document identity and an ordered chain of containing-frame XPaths, while its single target XPath remains a standard expression evaluated in that document. This preserves same-node verification and makes frame targets usable without inventing a compound XPath syntax; one aggregate capture and validation budget bounds work across documents, and a lifecycle change to a selected target’s frame or ancestor invalidates its capture. Unrelated frame events are excluded by [target revalidation](0028-validate-retained-targets.md).
