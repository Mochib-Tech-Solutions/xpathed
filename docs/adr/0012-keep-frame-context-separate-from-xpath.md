# Keep frame context separate from document XPath

Issue #4 extends the accepted current-page contract into nested frame documents. Each found target carries its capture-owned frame/document identity and an ordered chain of containing-frame XPaths, while its single target XPath remains a standard expression evaluated in that document. This preserves same-node verification and makes frame targets usable without inventing a compound XPath syntax; one aggregate capture and validation budget bounds work across documents, and a frame lifecycle change invalidates the entire capture rather than mixing document states.
