# Separate target resolution from action execution

The assignment implementation resolves one target for a natural-language instruction and highlights it for inspection. The user interacts manually with the managed browser through noVNC; the initial client has no Execute step button or instruction-driven action executor. Keeping resolution separate from execution lets us compare returned XPath expressions without action retries or repairs concealing an incorrect initial selection. Active exploration is provisionally excluded; result fields and state checks are detailed in specification issue #1.
