# Separate target resolution from action execution

The assignment resolves each action's target in the current page and highlights it for inspection. The user interacts manually with the managed browser through noVNC; the client has no Execute step button or instruction-driven action executor. Keeping resolution separate from execution lets us compare returned XPath expressions without action retries or repairs concealing an incorrect selection. Following the assignment replies and user confirmation on 2026-09-30, current-page resolution remains the accepted scope: missing eligible targets receive clear not-found results, non-interactable targets receive action-specific explanations, and resolution performs no scrolling, reveals, navigation or readiness waits. Multiple current-page actions are planned under [ADR-0008](0008-resolve-multiple-current-page-actions.md); the implemented contract remains documented separately.
